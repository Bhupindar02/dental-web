# dental-web

AURORA DENTAL ("We Design Smiles") — Modern dental clinic web application built with Next.js 14, Tailwind CSS, TypeScript, and interactive video scrubbers powered by Cloudinary.

## Features

- **Interactive Video Walkthroughs**: 3 scroll/scrub video experiences (Clinic Walkthrough, Transformation Gallery, Continuity & Comfort) loaded dynamically via Cloudinary CDN.
- **Sticky Navigation**: Section tracking, responsive mobile hamburger drawer, and direct appointment booking CTA.
- **Appointment Booking**: Split-layout appointment reservation form with real-time field validation.
- **Location & Google Maps**: Embedded interactive map container for the Vadodara, Gujarat clinic with directions.
- **Responsive & Modern Design**: Tailored healthcare aesthetic with teal branding (`#06b6d4`).

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Language**: TypeScript
- **Forms**: React Hook Form
- **Video Frames CDN**: Cloudinary
